# Vaishnavi Sharma — React Portfolio

A responsive, single-page React portfolio created from the details in the supplied internship resume.

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP and open the project folder in VS Code.
3. Open a terminal in the folder and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite.

## Before publishing
- Replace the LinkedIn URL if needed and add GitHub/portfolio links.
- Add phone number and expected graduation year if you want them displayed.
- Add verified project links, implementation details and screenshots. The resume notes that PDS stack/features need confirmation and that Crave & Crumb is not deployed.
- Google Fonts are loaded online; the app still has fallback fonts if unavailable.
